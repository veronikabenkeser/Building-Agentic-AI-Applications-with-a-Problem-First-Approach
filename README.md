# Building-Agentic-AI-Applications-with-a-Problem-First-Approach

This repo contains assignments from the Maven course "Building-Agentic-AI-Applications-with-a-Problem-First-Approach". The Agentic Workflows were implemented in Langflow.

## v0 Agentic Search System

Core intelligence engine that powers the AI Assistant:

* Take user queries and intelligently understand what they're asking for
* Format responses in a clean, professional style
* Use the Calculator Tool when needed
* Maintain a conversation memory to provide contextual responses

## v1 Agentic Search System

The AI Assistant now has 3 capabilities:

* Web search integration (for current information)
* RAG - Document search and understanding
* Agentic RAG
